# AI 教学评价系统 — 团队部署手册

> 本文档从零开始,任何人照做即可完成部署。无需 Docker,无需管理员权限装软件。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 服务器 | Windows Server 2016+ / Windows 10+ |
| 访问方式 | RDP 远程桌面(mstsc) |
| 磁盘空间 | 5GB 以上可用 |
| 外网能力 | 能访问国内镜像(华为云/阿里云/清华源) |
| 必备信息 | 1 个 LLM API Key(DeepSeek 或通义千问) |

**本系统架构(三服务):**
```
浏览器 ──公网:3000──▶ nginx(前端静态文件 + 反向代理)
                          │ /api 转发
                          ▼
                    后端 FastAPI(仅本机 8000)
                          │ HTTP 调用
                          ▼
                    算法服务 FastAPI(仅本机 8001)
                          │
                          ▼
                    LLM 厂商(DeepSeek/通义千问)
```

**端口规划:**
| 服务 | 端口 | 对外 | 说明 |
|------|------|------|------|
| nginx | 3000 | ✅ 是 | 浏览器访问入口 |
| 后端 | 8000 | ❌ 否 | 仅本机,nginx 转发 |
| 算法 | 8001 | ❌ 否 | 仅本机,后端调用 |
| RDP | 3389 | ✅ 是 | 远程桌面 |

## 二、云平台前置配置(必做,否则外部访问不了)

### 2.1 安全组放行 3000 端口(腾讯云示例)

1. 登录腾讯云控制台 → 云服务器 → 实例
2. 找到目标实例,点实例名进入详情
3. 左侧菜单点「安全组」
4. 点绑定的安全组名 → 「入站规则」标签
5. 点「添加规则」:
   - 来源: `0.0.0.0/0`
   - 协议端口: `TCP:3000`
   - 策略: 允许
6. 保存

> 阿里云同理:安全组规则 → 入方向 → 添加 3000/TCP 允许。
> 华为云一致。

### 2.2 确认 3389(RDP)已放行

安全组里确保 3389/TCP 已放行(一般云平台默认有),否则连不上远程桌面。

## 三、连接服务器并传代码

### 3.1 远程桌面连接

Win+R 输入 `mstsc`,或命令行:
```
mstsc /v:<服务器IP> /u:<用户名>
```
输入密码登录。

### 3.2 准备项目包(本地)

在本地开发机执行,生成精简部署包(排除 node_modules/.venv/dist 等大目录):

```powershell
cd D:\小学期项目\ai-teaching-evaluation-system
# 用 Python 打包,中文文件名兼容好
python -c "
import zipfile, os
src='.','.'
out='..\aies-deploy.zip'
excl={'node_modules','.venv','__pycache__','.git','chroma_data','logs','dist','.cache'}
with zipfile.ZipFile(out,'w',zipfile.ZIP_DEFLATED) as zf:
    for root,dirs,files in os.walk(src):
        dirs[:]=[d for d in dirs if d not in excl]
        for f in files:
            if f=='app.db' or f.endswith('.pyc'): continue
            full=os.path.join(root,f)
            zf.write(full, full.replace('\\','/'))
print('done')
"
```

生成 `aies-deploy.zip`(约 18MB)。

### 3.3 传到服务器

两种方式:

**方式 A:剪贴板传输(推荐,<50MB)**
- 本地复制 `aies-deploy.zip`(Ctrl+C)
- 远程桌面窗口内,目标位置粘贴(Ctrl+V)

**方式 B:本地磁盘映射**
- mstsc → 显示选项 → 本地资源 → 详细信息 → 勾选本地盘符
- 连接后在服务器"此电脑"可见本地盘,直接复制

### 3.4 解压

服务器上打开 PowerShell:
```powershell
New-Item -ItemType Directory -Force -Path C:\mfq | Out-Null
Expand-Archive aies-deploy.zip -DestinationPath C:\mfq -Force
```

最终目录结构:
```
C:\mfq\
└── ai-teaching-evaluation-system\
    ├── backend\
    ├── algorithm\
    ├── frontend\
    └── deploy\
```

## 七、启动服务

### 7.1 后台启动(推荐,关掉远程窗口仍运行)

```powershell
# 停掉可能残留的进程
Get-Process nginx -ErrorAction SilentlyContinue | Stop-Process -Force
Get-CimInstance Win32_Process -Filter "Name='python.exe'" -ErrorAction SilentlyContinue |
    Where-Object { $_.CommandLine -like "*uvicorn*src.main*" -or $_.CommandLine -like "*uvicorn*app.main*" } |
    ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
Start-Sleep 2

$py = "C:\mfq\Python311\python.exe"
$logs = "C:\mfq\logs"

# 1. 算法服务 8001
Start-Process $py -ArgumentList "-m","uvicorn","src.main:app","--host","127.0.0.1","--port","8001" `
    -WorkingDirectory "C:\mfq\ai-teaching-evaluation-system\algorithm" `
    -WindowStyle Hidden `
    -RedirectStandardOutput "$logs\algo.out.log" `
    -RedirectStandardError "$logs\algo.err.log"

Start-Sleep 3

# 2. 后端 8000
Start-Process $py -ArgumentList "-m","uvicorn","app.main:app","--host","127.0.0.1","--port","8000" `
    -WorkingDirectory "C:\mfq\ai-teaching-evaluation-system\backend" `
    -WindowStyle Hidden `
    -RedirectStandardOutput "$logs\be.out.log" `
    -RedirectStandardError "$logs\be.err.log"

Start-Sleep 5

# 3. nginx 3000
Start-Process "C:\mfq\nginx\nginx.exe" -WorkingDirectory "C:\mfq\nginx" -WindowStyle Hidden

Start-Sleep 2
```

### 7.2 验证服务

## 九、故障排查

### 9.1 外部访问不了(http://IP:3000 打不开)

**按顺序排查:**

1. **服务器本机能访问吗?**
   ```powershell
   (Invoke-WebRequest http://127.0.0.1:3000 -UseBasicParsing -TimeoutSec 3).StatusCode
   ```
   - 返回 200 → 服务正常,继续排查网络
   - FAIL → 看日志,服务没启动

2. **内网 IP 能访问吗?**
   ```powershell
   ipconfig | findstr "IPv4"
   # 假设内网 IP 是 10.0.0.8
   (Invoke-WebRequest http://10.0.0.8:3000 -UseBasicParsing -TimeoutSec 3).StatusCode
   ```
   - 返回 200 → Windows 防火墙没问题,是云安全组没放行
   - FAIL → Windows 防火墙拦截,见下条

3. **云安全组放行 3000 了吗?**
   - 腾讯云:控制台 → 安全组 → 入站规则 → TCP:3000 允许
   - 阿里云:安全组规则 → 入方向 → TCP:3000 允许

4. **Windows 防火墙放行了吗?**(管理员 PowerShell)
   ```powershell
   New-NetFirewallRule -DisplayName "AIES-3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
   ```
   > 加规则需管理员权限:开始菜单搜 PowerShell → 右键以管理员身份运行

### 9.2 服务启动不了

看错误日志:
```powershell
Get-Content C:\mfq\logs\be.err.log -Tail 20
Get-Content C:\mfq\logs\algo.err.log -Tail 20
```

**常见错误:**

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `No module named 'app'` | Python 找不到模块 | 命令前加 `$env:PYTHONPATH="."` |
| `No module named 'uvicorn'` | 依赖没装 | 重跑 `install.ps1` 或手动 `pip install -r requirements.txt` |
| `SECRET_KEY too short` | 后端 .env 没配 | 配 `SECRET_KEY` 为 32+ 字符 |
| `LLM_API_KEY not configured` | algorithm/.env 没配 | 配 `LLM_API_KEY` |
| `SQLite not found` | 数据库目录不存在 | 重跑 `app.seed --reset` |
| `vite not found` | 前端没构建 | 把本地 `frontend/dist` 传上去,或跑 `npm install && npm run build-only` |

### 9.3 前端白屏 / 404

```powershell
# 确认前端文件存在
dir C:\mfq\ai-teaching-evaluation-system\frontend\dist\index.html
# 确认 nginx 配置正确
Get-Content C:\mfq\nginx\conf\nginx.conf
# 重载 nginx
C:\mfq\nginx\nginx.exe -s reload
```

### 9.4 nginx 报 "unknown directive"

nginx.conf 文件有 BOM 头。修复:
```powershell
$content = Get-Content C:\mfq\nginx\conf\nginx.conf -Raw
$content = $content -replace "^\xEF\xBB\xBF", ""
[System.IO.File]::WriteAllText("C:\mfq\nginx\conf\nginx.conf", $content, (New-Object System.Text.UTF8Encoding($false)))
C:\mfq\nginx\nginx.exe -s reload
```

## 十、架构说明(给开发人员)

### 10.1 为什么不用 Docker

- 云服务器是 Windows Server,Docker Desktop 需要管理员权限和 Hyper-V
- 用户要求"仅当前用户安装",绿色版方案更合适
- 三服务都可用 Python/nginx 绿色版运行,无系统依赖

### 10.2 编码约定

- 所有部署脚本用**英文输出**(中文在 Windows GBK 环境易乱码)
- 配置文件用**无 BOM 的 UTF-8** 编码
- 路径全部用 `C:\mfq\` 绝对路径,不依赖环境变量

### 10.3 镜像源配置(国内加速)

| 资源 | 镜像 |
|------|------|
| Python | mirrors.huaweicloud.com/python |
| Node.js | mirrors.huaweicloud.com/nodejs |
| nginx | mirrors.huaweicloud.com/nginx |
| pip 包 | pypi.tuna.tsinghua.edu.cn/simple |
| npm 包 | registry.npmmirror.com |
| get-pip.py | mirrors.aliyun.com/pypi |
